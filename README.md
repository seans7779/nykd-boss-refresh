# NYKD BOSS刷新时间表 PWA

诺亚手机端BOSS刷新时间管理工具，支持手机访问。

## 📱 功能特性

- ⏰ **BOSS刷新时间计算** - 精确计算各服务器BOSS刷新时间
- 📅 **日历导出** - 导出BOSS时间到手机日历，支持提醒
- 🔔 **实时提醒** - 浏览器通知提醒即将刷新的BOSS
- 📊 **时间线视图** - 直观显示当日所有BOSS刷新时间
- 🖼️ **点位图管理** - 上传和管理BOSS点位图片

## 🛠️ 开发说明

### 文件结构
```
NYKD-BOSS-Refresh/
├── index.html          # 主页面
├── app.js             # 应用逻辑
├── manifest.json      # PWA清单文件
├── sw.js             # Service Worker
├── icon-192.png      # 应用图标 192x192
├── icon-512.png      # 应用图标 512x512
└── README.md         # 说明文档
```

### 自定义配置
- 修改 `manifest.json` 中的应用信息
- 更新 `sw.js` 中的缓存策略
- 替换图标文件为自定义图标

## 🐛 故障排除

### 日历导出问题
- 检查浏览器是否支持文件下载
- 确认日历应用支持ICS格式
- 时区问题已修复，时间应显示正确

### 通知问题
- 检查浏览器通知权限
- 确认Service Worker正常运行
- 部分浏览器需要用户交互后才能发送通知

## 📞 支持

如有问题或建议，请：
1. 检查浏览器控制台错误信息
2. 确认网络连接正常
3. 尝试清除浏览器缓存重新安装
