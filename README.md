# NYKD BOSS刷新时间表 PWA

诺亚手机端BOSS刷新时间管理工具，支持安装为手机应用。

## 📱 功能特性

- ⏰ **BOSS刷新时间计算** - 精确计算各服务器BOSS刷新时间
- 📅 **日历导出** - 导出BOSS时间到手机日历，支持提醒
- 🔔 **实时提醒** - 浏览器通知提醒即将刷新的BOSS
- 📊 **时间线视图** - 直观显示当日所有BOSS刷新时间
- 🖼️ **点位图管理** - 上传和管理BOSS点位图片
- 📱 **PWA支持** - 可安装为手机应用，支持离线使用

## 🚀 安装方法

### Android手机安装

1. **Chrome浏览器**：
   - 打开 `http://localhost:8000` (或你的服务器地址)
   - 点击地址栏右侧的"安装"图标
   - 或点击页面右下角的"安装应用"按钮
   - 选择"安装"确认

2. **其他浏览器**：
   - 打开浏览器菜单
   - 选择"添加到主屏幕"或"安装应用"
   - 确认安装

### iPhone/iPad安装

1. **Safari浏览器**：
   - 打开 `http://localhost:8000` (或你的服务器地址)
   - 点击底部分享按钮 📤
   - 选择"添加到主屏幕"
   - 编辑名称后点击"添加"

2. **其他浏览器**：
   - 建议先在Safari中打开链接
   - 然后按照上述步骤安装

## 📋 使用说明

### 基本功能
1. **添加服务器** - 点击"添加服务器"创建新服务器
2. **添加BOSS** - 点击"添加BOSS"添加不同等级的BOSS
3. **计算时间** - 输入当前时间和剩余分钟数，计算刷新时间
4. **查看时间线** - 点击"查看BOSS时间线"查看当日所有刷新时间

### 日历导出
1. 在时间线页面点击"导出到日历"
2. 下载生成的.ics文件
3. 在手机日历应用中导入该文件
4. 设置会自动添加10分钟提前提醒

### 提醒功能
1. 点击"开启提醒"按钮
2. 允许浏览器发送通知
3. 应用会在BOSS刷新前10分钟发送提醒

## 🔧 技术特性

- **PWA (Progressive Web App)** - 渐进式Web应用
- **Service Worker** - 离线缓存和后台同步
- **Web App Manifest** - 应用安装配置
- **响应式设计** - 适配各种屏幕尺寸
- **本地存储** - 数据保存在浏览器本地
- **ICS日历格式** - 标准日历文件格式

## 📱 PWA优势

1. **类原生体验** - 安装后像原生应用一样使用
2. **离线访问** - 无网络时也能查看已缓存的数据
3. **快速加载** - Service Worker缓存提升加载速度
4. **推送通知** - 支持后台推送通知
5. **自动更新** - 应用更新时自动提示用户
6. **跨平台** - 一套代码支持Android和iOS

## 🛠️ 开发说明

### 文件结构
```
NYKD-BOSS-Refresh/
├── index.html          # 主页面
├── app.js             # 应用逻辑
├── manifest.json      # PWA清单文件
├── sw.js             # Service Worker
├── icon-192.png      # 应用图标 192x192
├── icon-512.png      # 应用图标 512x512
└── README.md         # 说明文档
```

### 自定义配置
- 修改 `manifest.json` 中的应用信息
- 更新 `sw.js` 中的缓存策略
- 替换图标文件为自定义图标

## 🐛 故障排除

### PWA安装问题
- 确保使用HTTPS或localhost
- 检查manifest.json文件是否正确
- 确认Service Worker注册成功

### 日历导出问题
- 检查浏览器是否支持文件下载
- 确认日历应用支持ICS格式
- 时区问题已修复，时间应显示正确

### 通知问题
- 检查浏览器通知权限
- 确认Service Worker正常运行
- 部分浏览器需要用户交互后才能发送通知
